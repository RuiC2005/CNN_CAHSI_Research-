# CNN_CAHSI_Research-
CNN traffic sign classification research (CAHSI, with Dr. Nuri Yilmazer, TAMU-Kingsville). Python/Keras pipeline that audits, labels, and converts GTSRB, LISA, and custom real-world images into 25x25 datasets, then trains binary (stop vs. yield) and 43-class models. Reached 99.2% validation accuracy; presented at GMiS 2026.
